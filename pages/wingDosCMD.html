i386 kernel / os

Over

Dit is een echte kernel dat draaid op v86js.

Het meeste code is gemaakt in C en ik heb GCC compiler gerbuikt.

Besturing

Alleen commando's ver, dir, mkdir, echo, doen wat,

het werkt zoals een normale console commando scherm.

Wat het ik hiervan geleerd

Ik heb van dit project geleerd hoe bestuurings programma's werken,

en hoe ik het kan programmeren op i386 hardware.

Ook heb ik geleerd hoe ik assembly en C moet coderen voor bare metal i386 cpu,

maar dat is iets dat ik nog wel uitdagend vind.
